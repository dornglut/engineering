# Reports

Reports contain dated audits, reviews, inventories, and closeout evidence.

Use the filename form:

```text
YYYY-MM-DD-topic.md
```

A report may support a decision, but it does not become policy merely by existing. Durable outcomes must be incorporated into an ADR, standard, architecture document, initiative, or owning repository authority.

Reports may record live state as dated evidence. They must identify the observation date and must not be cited later as if they were current without renewed verification.
