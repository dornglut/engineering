# Engineering Portfolio

The Dornglut Engineering Portfolio is a GitHub Project for live prioritization, status, sequencing, and dates.

The project is operational state, not durable architecture. Every project item must link to an issue, pull request, initiative, or ADR that owns the underlying work or decision.

Recommended fields:

- status;
- priority;
- repository;
- initiative;
- work type;
- target milestone;
- blocked by;
- next action.
