# Engineering Portfolio

The Dornglut Engineering Portfolio is planned but is not yet an active authority.

It becomes the live GitHub Project for priority, status, sequencing, and dates only after:

- the organization Project is created;
- its field model is accepted;
- active repository issues and initiatives are linked;
- the activation is recorded in this repository.

After activation, the project remains operational state rather than durable architecture. Every project item must link to an issue, pull request, initiative, or ADR that owns the underlying work or decision.

Recommended fields:

- status;
- priority;
- repository;
- initiative;
- work type;
- target milestone;
- blocked by;
- next action.
